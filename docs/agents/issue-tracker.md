# Local issue tracker

Tickets live in `.scratch/lab06/issues/`, one Markdown file per ticket.
Work only tickets whose blocking requirements are satisfied. Source requirements
remain GUIDE.md, BENCHMARK.md, RULES.md, RUBRIC.md and SUBMISSION.md.
Implementation is not evidence of successful execution: record skipped checks,
missing inputs and pending human audit in each ticket and in
`docs/implementation-status.md`. No GitHub issues are published by this workflow.
